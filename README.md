# SYNK

SYNK is a Godot 4.7 rhythm game with a 13-lane highway, a built-in Eclipse demo, imported music, custom chart recording and editing, and Auto Play.

Read the [full game guide and project reference](GAME.md) for gameplay, chart creation, settings, saved data, development commands, and export notes.

On the development machine, launch `Play-SYNK.cmd` or open the project with `Open-SYNK.cmd`. In another checkout, open `project.godot` in Godot 4.7 and press **F5**.
